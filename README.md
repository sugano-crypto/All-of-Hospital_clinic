# 全国医療機関情報検索サイト

すがコンサルティング＆パートナーズ向けの医療機関検索・DMリスト抽出・顧問先届出確認アプリの初期実装です。

## 専用環境

- GitHub: `sugano-crypto/All-of-Hospital_clinic`
- Supabase: `leczxapskgixlzykdovz`

今回専用の空リポジトリから新規実装しました。他プロジェクトのコード・データ・環境変数・Secretsは利用していません。

## 起動

Node.js 22以降で実行します。

```sh
npm ci
npm run dev
```

接続設定がなくても「架空データでデモを開く」から操作できます。デモの変更・顧問先メモ・画像はメモリ上のみで、終了すると消えます。

```sh
npm test
python -m unittest discover -s tests -p 'test_*.py' -v
npm run build
```

ブラウザ検証にはChromiumが必要です。`playwright.config.js` の `executablePath` を環境に合わせて変更します。起動中のアプリに対して `npm run test:browser` を実行してください。

## 実装内容

- 医療機関名・所在地・都道府県・病床数・開設者区分・診療科目の複合検索
- 届出の正式名称検索と「あり・なし・未確認」の抽出
- 抽出した全件のCSV（UTF-8 BOM）・Excel（xlsx）出力
- 顧問先登録・管理メモ・届出一覧
- CSVの検証プレビューとトランザクションによる入替
- Supabaseログイン、許可利用者、所有者単位のRLS
- 8厚生（支）局の公表先台帳と、原本ファイル取得・全シート読込の監査スクリプト
- 20日取得・25日失敗局のみ再取得する監査ワークフロー定義（初期状態では定期実行無効）

## 現在の制限

全国データの運用開始は未完了です。原本取得監査は、全国の医療機関・届出項目が意味的に全件変換されたことを保証しません。実資料の局別パーサ、正式名称対応マスター、47都道府県の網羅性と全項目の突合、月次DB反映処理は未完了です。

今回の開発環境では厚生局のホストが通信許可に入っておらず、公式サイトへの実ファイル取得がプロキシの403で停止しています。Supabaseの接続変数・認証も未設定のため、本番DBにはまだ適用していません。

初期版は利用者ごとのデータをブラウザへ読み込んで絞り込みます。全国実データの件数・応答時間を測定し、運用前にサーバー側検索とストリーミング出力へ移行してください。
